# web_Application_python

## О проекте

web_Application_python — локальное веб-приложение на Flask для запуска скриптов обработки статистики ВЦКП и ЦСМ. Интерфейс позволяет работать с исходными файлами, запускать обработку, просматривать логи выполнения и скачивать результаты.

## Возможности

- **Запуск скриптов:** преобразование Word в Excel, объединение Excel-файлов, обработка статистики ЦСМ и формирование отчётов.
- **Работа с файлами:** загрузка, просмотр, скачивание и удаление файлов.
- **Управление группами:** просмотр и редактирование файла `group_file_origin.xlsx`.
- **Журнал выполнения:** просмотр логов и статуса запущенных задач.
- **Ежемесячные отчёты:** быстрый запуск обработки статистики за предыдущий календарный месяц, если соответствующий сценарий предусмотрен установленной версией проекта.

## Требования

- Windows 10 или новее.
- Python 3.10 или совместимая версия.
- Установленные зависимости из `requirements.txt`.
- Исходные файлы статистики и таблица групп.

Для работы с Excel используется `pandas` и библиотека `openpyxl`.

## Установка

Открой терминал в корневой папке проекта.

Создай виртуальное окружение, если оно ещё не создано:

```bash
python -m venv .venv
```

Активируй его в Windows:

```bat
.venv\Scripts\activate
```

Установи зависимости:

```bash
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

Если файла `requirements.txt` нет, установи необходимые библиотеки вручную:

```bash
python -m pip install flask pandas openpyxl
```

## Запуск приложения

Из корневой папки проекта выполни:

```bash
python web_app.py
```

После запуска открой браузер и перейди по адресу:

http://127.0.0.1:5000

Чтобы остановить приложение, нажми `Ctrl+C` в терминале.

## Основные разделы

### Главная страница

Содержит доступные операции обработки статистики и навигацию по приложению.

### Скрипты обработки

Выбери необходимую операцию, укажи исходные данные и параметры, если они требуются, затем запусти обработку. Во время выполнения можно просматривать журнал и проверять статус задачи.

### Файлы

Используется для загрузки и управления исходными и результирующими файлами.

### Группы

Позволяет просматривать и редактировать таблицу групп, используемую при формировании отчётов.

Файл групп по умолчанию:

`group_file_origin.xlsx`

Перед формированием отчёта убедись, что нужный файл групп доступен приложению.

### Ежемесячные отчёты

Если в установленной версии доступен раздел быстрого отчёта, выбери тип статистики и соответствующий исходный файл. Проверь результат выполнения в журнале и скачай сформированный отчёт.

## Структура проекта

Основные элементы проекта:


## Важные правила

- Не удаляй исходные файлы статистики до проверки результата обработки.
- Не переименовывай файлы и папки, на которые ссылается приложение, без соответствующего изменения настроек.
- Не изменяй логику обработки данных в скриптах без необходимости.
- Перед обновлением проекта делай резервную копию исходных файлов.
- После обработки проверяй код завершения и сообщения в журнале.

## Решение распространённых проблем

### Ошибка `Import openpyxl failed`

Установи библиотеку в то же виртуальное окружение, из которого запускается Flask:

```bash
python -m pip install openpyxl
```

### Ошибка `500 Internal Server Error`

Посмотри traceback в терминале, где запущен `web_app.py`. Он показывает причину ошибки и строку кода, на которой она возникла.

### Не скачивается файл

Проверь, что файл существует, а используемая версия Flask совместима с параметрами `send_file` или `send_from_directory`.

### В логах вместо кириллицы отображаются знаки вопроса

Проверь кодировку запускаемых Python-процессов и настройки чтения вывода в `web_app.py`.

### Скрипт не находит исходный файл

Убедись, что файл находится в ожидаемой рабочей папке, его имя введено правильно и у приложения есть доступ к нему.
